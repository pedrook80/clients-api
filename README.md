# clients-api

A simple Node.js REST API for managing clients.

## Getting Started

### Run locally (development)

```bash
npm install
npm run dev
```

### Run with Docker

```bash
docker-compose up --build
```

⚠️ Migrations are run automatically on container startup if not already applied.
If not just run 

```bash
npm run migrate
```

### API Documentation

http://localhost:3000/docs
